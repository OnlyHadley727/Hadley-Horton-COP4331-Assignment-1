COLORS Application



Description



A web application that allows users to log in and add/search for colors specific to their account. The application has a HTML/CSS front end with a PHP backend API that communicates with a MySQL database.



Technologies used



\- HTML

\- CSS

\- JavaScript

\- PHP

\- MySQL

\- Apache

\- Linux

\- LAMP stack



High level setup instructions



1\. Install and configure Apache, PHP, and MySQL

2\. Create the COP4331 MySQL database and the required tables

3\. Place the project files in the Apache web server directory

4\. Configure the database connection information in the PHP API files

5\. Make sure Apache and PHP are running and that the application can access the MySQL database





How to run and access the application



Create a DigitalOcean droplet and a GoDaddy domain name to host the server or run on your computer locally using localhost



Assumptions and limitations



\- A working LAMP environment

\- The COP4331 MySQL database and required tables must exist

\- Database credentials are specific to the environment and aren't included here for privacy, users must configure their own database credentials
